## Guiding Principles

> **"Adoption is the primary risk. Simplicity trumps features."**

SASU volunteers are older and less tech-savvy. Every new feature must pass the question: *"Will this confuse a 65-year-old on a phone?"*

- Minimum 48px touch targets
- Plain English everywhere: "Safety issue" not "priority: critical"
- Bottom navigation on mobile (not sidebar)
- Maximum 3 steps to complete any primary action
